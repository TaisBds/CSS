# 🎨 Projeto CSS - Conhecimentos Básicos

Este repositório reúne atividades práticas desenvolvidas com foco em **CSS**, explorando desde conceitos básicos até a criação de layouts para páginas web.

---

## 🚀 Conteúdo do Repositório

Aqui você encontrará:

### 📄 Arquivos HTML
- `index (1).html` → Primeiros passos para criação de portfólio  
- `index (2).html` → Exercícios de conhecimentos básicos  
- `index (3).html` → Prática de estrutura HTML + CSS  
- `index (4).html` → Continuação dos estudos  
- `index.html` → Projeto de portfólio  

### 🎨 Arquivos CSS
- `style (1).css` → Estilização inicial do portfólio  
- `style (2).css` → Prática de estilos básicos  
- `style (3).css` → Exercícios de CSS  
- `style.css` → Estilo principal do portfólio

## 🧠 Conceitos Trabalhados

Durante as atividades, foram aplicados:

- ✔️ Seletores CSS  
- ✔️ Cores e fundos  
- ✔️ Tipografia  
- ✔️ Espaçamento (margin e padding)

- ✔️ Layout básico  
- ✔️ Organização de estilos
